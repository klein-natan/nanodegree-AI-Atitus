# IA Generativa

O curso fecha usando modelos que outra pessoa treinou. Nas duas aulas
deste módulo você roda um modelo aberto de 494 milhões de pesos sem chave
de API, aprende a escrever o prompt que ele entende, e constrói uma
aplicação que responde perguntas sobre um documento seu.

A arquitetura é a mesma que você montou no módulo anterior. O que muda é
que agora você usa, em vez de treinar.

| Aula | Conteúdo | Status |
|---|---|---|
| [Aula 13 — Modelos de Fundação](aula-13-modelos-de-fundacao.md) | Rodar um modelo pronto, e aprender a falar com ele | Disponível |
| [Aula 14 — Uma Aplicação de Verdade](aula-14-aplicacao-rag.md) | Buscar antes de responder, e medir se melhorou | Disponível |
