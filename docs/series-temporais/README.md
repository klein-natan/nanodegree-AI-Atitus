# Séries Temporais

Muitos problemas de previsão não são "prever um valor a partir de outro".
São "prever o futuro de algo que muda com o tempo". Vendas de uma loja,
número de acessos a um site, temperatura de uma cidade: tudo isso é uma
série temporal.
